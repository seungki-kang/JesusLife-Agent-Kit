# 제품과 데이터 경계

| 제품 | 원본 소유 범위 |
|---|---|
| ChurchOS | 교회·조직·역할·화이트라벨·통합 사용자 경험 |
| JLBible | 성경 읽기·통독·묵상 |
| JLPrayer | 개인·공동체 기도·중보 |
| 너랑나랑 | 십자가 문답 세션·완료 기록 |
| 생명일기 | 개인 영성 기록·음성 전사 |
| JesusLife Academy | 교재·강의·과정·진도·수료 |
| CHGO | 개념·관계·근거·추천·추론 |

JesusLife One은 별도 앱으로 만들지 않고 ChurchOS에서 통합 제공한다. Academy의 교육 콘텐츠와 CHGO의 의미·추론 엔진을 분리한다.
데이터 원본은 한 제품만 소유하며 타 제품은 API/이벤트와 안정된 ID로 참조한다. PostgreSQL은 업무 기록 원본, 객체 저장소는 파일, 벡터 DB는 파생 검색 색인이다.
개인 영성 기록을 공용 지식으로 자동 승격하지 않는다. 공유 범위·동의·철회·보유기간·삭제 흐름과 교회 테넌트 격리를 명시한다. 실제 기록 대신 합성 자료로 검증한다.
