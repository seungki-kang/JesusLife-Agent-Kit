# CHGO 후보와 정본

거버넌스, Constitution, ID 계약, 레지스트리, 검증기를 먼저 읽고 대상 Canonical ID·근거·버전·하위호환성을 추적한다.
개념·관계·추론은 출처·근거가 있는 candidate로 시작한다. candidate, reviewed, approved, deprecated를 구분하고 승인된 의미를 보존한다.
신학 정본·저자 해석·승인 관계 의미 변경, Canonical ID 발급·병합·폐기, 개인 영성 기록의 공용 지식 승격은 AUTHOR_REVIEW_REQUIRED다. AI가 사람의 승인이나 서명을 생성하지 않는다.
스키마, 참조 무결성, 중복 ID, 근거, 기존 질의·추론 회귀를 프로젝트 검증기로 확인한다. DB·네트워크·서비스 활성화는 별도 승인 범위를 따른다.
