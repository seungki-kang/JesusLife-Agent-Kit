# FastAPI·동기화 구현

대상 경로·브랜치·git status·미커밋 diff와 Python 의존성·프로젝트 검증 명령을 확인한다. 초기 구조는 단일 FastAPI 배포의 제품별 모듈형 모놀리스다. core는 설정·인증·동의·권한·오류·감사를 담당한다.
제품 내부 모델을 다른 모듈에서 직접 참조하지 말고 API/이벤트 계약을 유지한다. 서버에서 인증·권한·테넌트 격리를 최종 검사하며 사용자·교회·역할 ID를 구분한다. 토큰·비밀키·민감 원문은 저장소와 로그에 넣지 않는다.
계약의 버전·오류·멱등성, 동기화의 충돌·재시도·중복·삭제 전파·오프라인 복구를 확인한다. 기존 클라이언트 호환성을 보존한다.
DB 구조·인증 경계·개인정보 공유 변경은 AUTHOR_REVIEW_REQUIRED다. migration 실행·외부 API 연결·실제 정보 수집은 승인 범위 확인 후 수행한다. 백업·롤백과 새 설치·기존 버전 업그레이드를 검증한다.
프로젝트 formatter·linter·type checker·unit/integration test와 필요한 빌드를 실행한다. 권한 거부·교차 테넌트·재시도 회귀를 포함한다.
