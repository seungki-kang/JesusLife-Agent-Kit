# 품질 게이트와 보고

변경에 가까운 회귀 검사부터 프로젝트의 전체 테스트·분석·필요한 빌드로 넓힌다. DB는 새 설치·기존 버전 업그레이드·백업 복구를 포함한다. 테스트 자료는 합성 자료를 사용한다.

| 상태 | 근거 |
|---|---|
| PASS | 실제 실행한 검증이 성공함. 명령과 범위를 기록 |
| FAIL | 실행한 검증이 실패함. 오류와 영향을 기록 |
| NOT_RUN | 미실행. 도구 부재·환경·범위 등 이유 기록 |
| BLOCKED | 진행에 필요한 조건 미충족. 해소 조건 기록 |
| AUTHOR_REVIEW_REQUIRED | 신학·ID·공유·DB 구조·인증 경계에 사람 검토 필요 |

결과, 변경 파일, 실행 명령·종료 코드, 미실행 검증, 남은 위험·승인 대상을 보고한다. 일부 검사 성공을 전체 릴리스 PASS로 확대하지 않는다. commit·push·merge·tag·release·배포는 사용자 승인 없이 수행하지 않는다.
