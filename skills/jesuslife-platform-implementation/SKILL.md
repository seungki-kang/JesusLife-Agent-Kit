# JesusLife 개발

작업 전에 [공통 보호 규칙](../jesuslife-platform-development/references/common-rules.md)을 적용하고 [개발 자료 안내](references/workflow.md)를 읽는다. 적용할 스킬과 순서를 먼저 알린다. 라우터를 재호출하지 않는다.

변경 전 경로·브랜치·Git 상태와 미커밋 변경을 확인하고 최소 변경·복구 가능성·회귀 검증을 지킨다. 불명확하거나 위험하면 변경 없이 질문한다. 중요 경계는 AUTHOR_REVIEW_REQUIRED로 분류하고 필요한 승인 전 변경하지 않는다. 세부 구현 절차와 검증·보고는 자료 안내에 연결된 references를 따른다. 공통 자료가 없으면 BLOCKED로 보고한다.
