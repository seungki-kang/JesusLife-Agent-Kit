# 설계 자료 안내

설계 스킬의 자료 진입점이다. 절차 원본은 기존 라우터 단독 설치와의 호환성을 위해 공통 references에 한 번만 유지한다. 문서를 복사하지 않는다.

1. 작업 시작 전 [공통 보호·질문·승인·사전 안내 규칙](../../jesuslife-platform-development/references/common-rules.md)을 적용한다. 라우터를 재호출하지 않는다.
2. 제품·데이터 소유권을 정할 때 [제품 경계](../../jesuslife-platform-development/references/project-boundaries.md)를 읽는다.
3. 기획·흐름·API 계약 초안·ADR·대안·로드맵은 [설계 절차](../../jesuslife-platform-development/references/design-workflow.md)를 따른다.
4. CHGO 후보 설계에 한해 [온톨로지의 후보·정본 경계](../../jesuslife-platform-development/references/ontology-workflow.md)를 읽는다. 설계만 요청하면 구현하지 않는다.
5. 외부 보조 스킬을 검토할 때만 [외부 스킬 규칙](../../jesuslife-platform-development/references/external-skill-routing.md)을 읽는다.
6. 결과는 [품질 게이트](../../jesuslife-platform-development/references/quality-gate.md)로 보고한다.

공통 자료가 없으면 보호 규칙을 확인할 수 없으므로 변경 없이 BLOCKED로 보고한다. 구현 절차 전체를 미리 읽지 않는다.
