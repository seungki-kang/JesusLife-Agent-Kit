# JLPrayer Codex 작업 지침

이 저장소의 모든 작업에 `jesuslife-platform-development`를 자동 적용한다. JLPrayer는 사용자 서비스이며 GPO는 기도 온톨로지 기술 계층이다.

## 핵심 원칙

- 기도 요청의 개인·소그룹·교회·공개 범위를 명확히 구분한다.
- 제3자 이름과 민감정보는 최소 수집하며 공개 전 동의를 확인한다.
- 알림, 공유, 기도 참여, 응답 기록은 철회·차단·삭제 흐름을 포함한다.
- 개인 기도 원문을 CHGO 또는 GPO 공용 지식으로 자동 승격하지 않는다.
- 로그와 분석 도구에 기도 본문을 출력하지 않는다.

작업 전 브랜치·Git 상태·공개 범위·권한·보유기간을 확인한다. 실제 메시지 발송, 외부 공유, 개인정보 수집, 배포, commit·push·merge는 별도 승인 없이 수행하지 않는다.

## 검증

공개 범위, 권한, 차단·철회·삭제, 알림 중복, 민감정보 로그 노출을 우선 시험한다. 앱과 API의 정적 분석, 관련 테스트, 전체 테스트, 빌드를 수행한다.

결과는 `PASS`, `FAIL`, `NOT_RUN`, `BLOCKED`, `AUTHOR_REVIEW_REQUIRED`로 보고한다.
